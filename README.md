
# Ali Bigdeli

### Software Engineer | AI4SE Researcher | Computer Science Ph.D. Student

I am a Computer Science Ph.D. student at Colorado State University
with over 15 years of professional experience in software engineering,
software architecture, and distributed systems.

My professional background includes designing and developing
enterprise software platforms, distributed data processing systems,
and scalable backend applications, as well as leading software
engineering teams.

My current research focuses on Artificial Intelligence for Software
Engineering (AI4SE), particularly large language models, autonomous
software engineering agents, and software reliability.
